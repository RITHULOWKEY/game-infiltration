# Game Infiltration

An interactive 3D game built with Babylon.js, React, and TypeScript. Navigate through dynamic environments, complete objectives, and immerse yourself in a responsive gaming experience.

🎮 [Play the Demo](https://metro9infil.vercel.app/)

## Features

- **3D Rendering** - Powered by Babylon.js for smooth, performant graphics
- **Interactive Gameplay** - Real-time player controls and world interactions
- **Responsive Design** - Optimized for desktop and mobile devices
- **Modern UI** - Built with Radix UI components and Tailwind CSS
- **State Management** - Persistent save functionality with local storage
- **Full-Stack** - React frontend with Express.js backend

## Tech Stack

**Frontend:** React 19, Babylon.js, TypeScript, Tailwind CSS, Vite  
**Backend:** Express.js, Node.js  
**UI:** Radix UI, Lucide React, Framer Motion

## Installation

```bash
git clone https://github.com/RITHULOWKEY/game-infiltration.git
cd game-infiltration
pnpm install
pnpm dev
```

## Available Scripts

```bash
pnpm dev       # Start dev server
pnpm build     # Build for production
pnpm start     # Run production
pnpm check     # Type check
pnpm format    # Format code
```
